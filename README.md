# Angular Cart App for Digital Room Exam


# HOW TO SETUP 
- Must have Angular 17 and Node.js 22 Installed
- To run the application, enter "ng serve -o" in the terminal.
- It will automatically open the application in the browser, or you may access http://localhost:4200 directly

# FEATURES IMPLEMENTED
- Coded in a Component,service and mock structure
- Product Listing Using Mock API
- Products have their respective Ids, images, name,quantity and prices
- Implemented a Add to Cart function
- Implemenented the required cart functionality 
- The SAVE10 Coupon feature is implemented and subtotal will adjust accordingly when quantities in the cart are adjusted
- The coupon discount is calculated per item to also handle the minimum/maximum discount requirements
- Cart Persistence is also implemented by using localstorage
